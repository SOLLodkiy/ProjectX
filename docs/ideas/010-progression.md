# 010. Прогресс: уровни, достижения и серии

Идея предложена агентом по просьбе пользователя доработать контент.

## Суть

Долгосрочные цели поверх монеток: уровни игрока, достижения и ежедневные серии.

## Механика

- **Когда срабатывает:** при любых действиях и заходе в программу.
- **Что происходит:**
  - **Опыт и уровни:** любые действия дают опыт. С уровнем игрок получает звания (Новичок → Кликер → Коллекционер → ... → Легенда рабочего стола), монеты и косметику.
  - **Достижения:** 100+ штук с пиксельными значками: «1000 кликов», «100 часов музыки», «Открыть 50 сайтов», скрытые и шуточные («Открыл Блокнот в 3 ночи»).
  - **Ежедневная серия:** ежедневный вход даёт награду, растущую с длиной серии, с одним бесплатным пропуском в неделю.
  - **Итог дня:** пиксельный отчёт по дню: монеты, рекорды, лучшая активность.
  - **Цели недели:** крупные цели с большой наградой.
- **Длительность и частота:** постоянно.
- **Как отключается:** уведомления отключаются в настройках, прогресс всё равно считается.

## Настройки

Показ уведомлений о достижениях и итога дня.

## Возможные конфликты

Использует данные из 005. Награды проходят через общую формулу дохода из 007.
