# 007. Улучшения

## Суть

Магазин постоянных улучшений за монетки, например +1 монетка за клик или монетка за ПКМ.

## Механика

- **Когда срабатывает:** покупка в магазине, который открывается из HUD или трея.
- **Что происходит:** улучшение действует сразу и навсегда. Многоуровневые улучшения дорожают: `цена = база × множитель ^ уровень`.
- **Длительность и частота:** постоянно.
- **Как отключается:** купленные улучшения не отключаются.

### Дерево улучшений (предложение агента)

Улучшения организованы в ветки, некоторые открываются только после предыдущих.

| Ветка | Улучшения |
| --- | --- |
| Клики | +1 монетка за ЛКМ (многоуровневое); монетка за ПКМ; монетка за среднюю кнопку; монетка за прокрутку; шанс критического клика ×10; комбо за быстрые серии |
| Клавиатура | Маленький доход за напечатанный текст (без записи содержимого); бонус за длинные сессии |
| Хронометраж | Множители для видео, музыки и игр (отдельно); бонус за досмотр; фоновое прослушивание с повышенным доходом |
| Пассив | Монетный генератор: доход просто за включённую программу (небольшой); проценты с накоплений |
| Задания | Больше слотов заданий; бесплатная смена задания; повышенная награда; ускорение обновления |
| Усложнения | Предупреждение раньше; короче длительность; щит от следующего усложнения; бонус за выживание |
| Экономия | Скидка на разблокировки; купоны; счастливый шанс бесплатной покупки |
| События | Чаще появляются золотые монеты; сильнее сундуки; магнит для монеток |

Новые улучшения добавляются одной записью в файле данных, а эффекты — отдельными модулями. Всего предполагается 40+ улучшений.

## Настройки

Нет.

## Возможные конфликты

- 002 и 003: итоговая формула дохода должна быть единой для всех источников.
- 009: множитель усложнений применяется после улучшений.
- Клавиатура: доход только за факт нажатия, содержимое не сохраняется (приватность из 001).
