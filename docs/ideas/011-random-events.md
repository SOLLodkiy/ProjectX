# 011. Случайные события и сундуки

Идея предложена агентом по просьбе пользователя доработать контент.

## Суть

Внезапные приятные события разбавляют рутину и дают повод отвлечься на игру.

## Механика

- **Когда срабатывает:** случайно, предложение: в среднем раз в 15–30 минут, не во время полноэкранных игр и ввода пароля.
- **Что происходит:** событие из списка ниже.
- **Длительность и частота:** от секунд до нескольких минут.
- **Как отключается:** настройка отключает отдельные события.

### События

| Событие | Что происходит |
| --- | --- |
| Золотая монета | Появляется на экране на 8 секунд, клик даёт крупную сумму |
| Монетный дождь | Монетки падают с верха экрана, их нужно ловить |
| Бегущий гоблин | Пробегает по экрану с мешком монет: успей кликнуть |
| Сундук | Обычный, редкий или легендарный: случайные монеты, бустеры, косметика |
| Час удачи | Доход ×2 на 5 минут |
| Распродажа | Скидка на случайный сайт или программу |
| Колесо фортуны | Бесплатный ежедневный спин, дополнительные за монеты |
| Босс | Раз в день пиксельный босс: кликай по нему, чтобы победить и забрать награду |
| Загадка | Простая мини-загадка или викторина за монеты |
| Торговец | Появляется редкий продавец со случайными предложениями на короткое время |
| Сезонные события | Новый год, Хэллоуин и другие: темы и особая награда |

Каждое событие — отдельный модуль, расписание и шансы хранятся в данных.

## Настройки

Частота событий, включение и отключение отдельных событий.

## Возможные конфликты

- 009: событие не появляется одновременно с усложнением, чтобы не перегружать экран.
- Режим «Не беспокоить» из 009 относится и к событиям.
- Клик по событию не должен срабатывать в окно, которое находится под ним.
